# Number Guessing Game

## Description
A Java console application that challenges users to guess a randomly generated number. This project focuses on fundamental logic loops, robust defensive programming to handle invalid user inputs gracefully, and session persistence to accurately track gameplay states.

## How to Run
1. Ensure you have the Java Development Kit (JDK) installed on your machine.
2. Clone this repository to your local machine.
3. Open the project folder in NetBeans IDE.
4. Click the **Run Project** button (the green play arrow) in the top toolbar, or press `F6`, to start the application in the console.
